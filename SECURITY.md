# Security · Sicurezza

**English** · [Italiano](#italiano)

Maschera handles sensitive spreadsheets, so security reports are welcome.

## Reporting a vulnerability

Please **do not open a public issue**. Use
[private vulnerability reporting](https://github.com/alexcard3/maschera-xlsx/security/advisories/new) on GitHub.
Describe the problem and how to reproduce it, **with invented data only**: never attach real files or real names.
You will get an answer as soon as possible; this is a personal project, so there is no guaranteed response time.

Examples of what counts as a vulnerability:
- real values that survive in the anonymized file (in any part of the package);
- a way for the page to send data over the network;
- a spreadsheet that can inject HTML or scripts into the page.

## Supported versions

Only the latest release receives fixes.

## Italiano

Maschera tratta fogli di calcolo riservati, quindi le segnalazioni di sicurezza sono benvenute.

## Segnalare una vulnerabilità

Per favore **non aprire una issue pubblica**. Usa la
[segnalazione privata delle vulnerabilità](https://github.com/alexcard3/maschera-xlsx/security/advisories/new) di
GitHub. Descrivi il problema e come riprodurlo, **solo con dati inventati**: non allegare mai file veri o nomi veri.
Riceverai una risposta appena possibile; è un progetto personale, quindi non c'è un tempo di risposta garantito.

Esempi di vulnerabilità:
- valori veri che restano nel file anonimo (in qualunque parte del pacchetto);
- un modo con cui la pagina possa mandare dati in rete;
- un foglio di calcolo che riesca a iniettare HTML o script nella pagina.

## Versioni supportate

Solo l'ultima versione riceve correzioni.
